# Contributing to Standard HTML Formats

We welcome contributions to standardize our organizational documents.

## Guidelines
1. Ensure all HTML templates are standalone (unless specific assets like `examnurture_logo.jpg` are used).
2. CSS must be clearly formatted and commented.
3. Templates should be tested for both screen display and PDF printing.
4. Update the `PROJECT_STATUS.md` with any new templates added.

## Process
1. Create a branch for your template.
2. Add the `.html` file into the appropriate directory (e.g., `/JD`).
3. Commit and push for review.
